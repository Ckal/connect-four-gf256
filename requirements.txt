# Runtime dependencies for the Connect Four GF(256) release.

# Docker deployment uses; a CUDA build of the same torch version works

# and the read-out is float32, so the two paths agree to float precision).
#
#   pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
#
# The trailing "+cpu" local version is what the PyTorch CPU index serves.
# For a GPU workstation, install the matching CUDA build instead:
#
#   pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
